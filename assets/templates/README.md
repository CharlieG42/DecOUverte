# Template vierge — DéCOuverte

Placez ici le fichier `template_vierge.pdf` : affiche A4 portrait contenant
uniquement la charte graphique (logo, fond, boussole, titre, accroche)
avec les zones éditables **vides**.

L'application utilise ce PDF comme arrière-plan et superpose les zones
éditables (date, lieu, horaire, type, public, inscription, téléphones, QR code)
aux coordonnées définies dans `lib/constants.dart`.

## Format

- A4 portrait (210 × 297 mm)
- PDF standard (compatible pdfrx)
- Texte des zones éditables absent ou effacé
